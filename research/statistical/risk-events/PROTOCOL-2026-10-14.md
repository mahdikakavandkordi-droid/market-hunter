# Risk-event probability hypothesis v1 — 14 October 2026

New, bounded hypothesis: causal volatility state and recent acceleration/shocks may forecast the probability of a future high-volatility window better than unconditional historical event rates. The decisive incremental question is whether acceleration/shock/downside features add information beyond a calibrated estimate using current volatility alone, especially when the current state is calm.

Both price vintages (pre-2020 and 2020–2026) have already been inspected. This entire new-target experiment is exploratory, NOT a fresh holdout. Publish this protocol and implementation before computing risk-event results. Do not tune against either vintage or claim that a successful historical result is blind validation.

## Event definition known at each origin

Let v20(t) be RMS of the last 20 daily log returns. At t, threshold q(t) is the linearly interpolated 80th percentile of the latest 252 v20 observations, including t. First eligible feature origin is t=271. This is an asset-relative recent high-volatility boundary, not a crash definition, a universal risk level or an 80% forecast coverage guarantee.

For h=5/10/20 native daily bars, the event is RMS of returns (t,t+h] > q(t). Each training label uses its OWN origin's frozen q, and becomes available only when its h-bar window ends. The threshold is never revised using later data. “Calm” means v20(t)<=q(t), known at t. Calm-origin event forecasts are the defined onset/advance-warning diagnostic. High-origin forecasts may merely predict persistence; do not describe those as new crisis warnings.

## Fixed model and baselines

Use the existing regularized logistic solver, lambda=20 summed loss, training-only scaling, 252 matured labels and refits every 21 native bars. Record penalized gradient diagnostics; fail rather than score a materially unconverged fit (max absolute gradient>1e-4). If a training sample has only one event class, return its Jeffreys-smoothed empirical probability and record the fallback. No hyperparameter search, no new macro variables or regime-conditioned strategy.

Full candidate has exactly four features: log(v20/q), log(v5/v20), abs(last return)/v20, and max(0,-last20-log-return)/(v20*sqrt(20)). Fixed positive numeric floors are 1e-12. These variables describe relative risk level, acceleration, current shock and recent downside; none predicts return direction by construction.

Matched competitive baselines: Jeffreys-smoothed matured-label event rate; smoothed event frequencies conditional only on current high/calm state (unseen state falls back to overall prior); one-feature logistic on log(v20/q), using identical fitting dates and available labels; EWMA(.94) Gaussian constant-future-variance probability P[chi-square(h)>h*q²/EWMAvar]; and a hard current-high indicator. The Gaussian EWMA probability is an explicitly idealized independent-normal benchmark, not a true tail-risk probability. One-feature logistic is the primary incremental comparator; beating only a prior or a misspecified Gaussian model is insufficient.

## Scoring and dependence

Primary horizon is h=10. Primary exploratory family consists of 36 paired candidate-versus-one-feature Brier comparisons: 9 assets x 2 periods x 2 populations (all origins; calm origins). Apply two-sided circular block-bootstrap tests, 999 replications, seed 20261014, block length 2h, sensitivity h/4h; Holm across the declared 36 tests. For calm-origin tests, preserve the complete native origin axis: multiply each paired loss difference by the calm indicator, rather than compressing gaps out of the series. Negative expected weighted difference corresponds to lower conditional Brier loss when the selected population has nonzero probability. Report weighted CI separately from descriptive conditional mean loss.

Other horizons, baselines, calibration, annual stability, AUC and fixed warning cutoffs .25/.50/.75 are secondary exploratory diagnostics. Record event prevalence, alert frequency, precision, recall, false-positive rate and Brier/log loss. Reliability bins are fixed [0,.2,.4,.6,.8,1]. Do not choose an alert threshold after inspecting its results. Report all non-overlap offsets, and event counts and contiguous event episodes; neither raw rows nor non-overlap rows are universally independent. Year grouping uses origin date. No outcome-based removal of crashes.

## Evidence and decision gate

Consume only normalized bars from the two existing complete hashed source bundles; verify their original file hashes. Keep separate chronological fits for each asset and each period; do not train an old forecast using post-2020 data. Preserve source-manifest hashes, exact input-bar bytes, source snapshots, fit parameters, origin thresholds, maturity dates, forecast probabilities and outcomes. New output directories cannot overwrite existing experiments. Exact replay must be offline and match source/configuration/input hashes.

A useful result must improve against calibrated current-level risk, be reasonably calibrated, and demonstrate calm-origin value in both periods with adequate events/sample size. Isolated favorable assets or horizons are not a cross-asset success. A gain driven only by already-high state is persistence information, not advance crisis prediction. No model will be integrated into Market Hunter/SMC, portfolios, Telegram or production, and no future monitoring schedule is activated by this experiment.
